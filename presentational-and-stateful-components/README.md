This will be another concept-based microlesson discussing the choices react developers make about what a component should do, and the dichotomy between presentational components that are stateless and accept props, and stateful components that manage the logic and data of an application.

Note, again, that changing your mind about where state should live, how many layers of components you need, and the pitfalls of passing props down through many generations of components are all reasonable challenges to new react developers.
